我的第一篇博客 - 搭建个人博客的喜悦
Created2024-03-27|生活随笔
今天是个特别的日子今天对我来说是个特别的日子，我成功搭建了自己的个人博客！作为一个热爱技术的人，拥有一个属于自己的博客一直是我的梦想。现在这个梦想终于实现了，我感到非常开心和激动。 为什么选择 Hexo？我选择使用 Hexo 来搭建博客，是因为它： 基于 Node.js，配置简单 支持 Markdown 写作 有丰富的主题选择 可以轻松部署到 GitHub Pages 社区活跃，文档完善 搭建过程虽然搭建过程中遇到了一些小问题，但通过查阅文档和社区讨论，最终都得到了解决。这个过程不仅让我学到了很多新知识，也让我体会到了技术带来的乐趣。 未来计划有了这个博客，我计划： 定期分享技术文章 记录学习心得 分享生活感悟 与更多志同道合的朋友交流 结语这是一个新的开始，希望这个博客能够见证我的成长，也希望能够通过这个平台结识更多朋友。让我们一起在技术的海洋中探索，在知识的道路上同行！ 写于 2024年3月27日
